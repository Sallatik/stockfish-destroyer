## Diagnosis
1. **Chronic shallow-depth tactical blindness (ply ~13–45)**: 8 mistakes of 100–250cp each before any king walk, well before the mating nets — this is the single biggest cp bleed in the game and is the already-queued TT+hash-move / killer-history work. This game reconfirms it should stay #1 in the queue.
2. **Missing check extensions cost us two near-losses (ply 47, 113)**: both times we walked the king into a forced mate that only survived because SF (Elo 2000) failed to find/execute the winning continuation the very next move (9988→831 and 9982→1213 eval swings on SF's reply). Against a stronger or less error-prone opponent these are outright losses. This is strictly a search-horizon problem, not eval: `best` move (Kd2, Rd3) held the *same* losing eval as before, so the loss was fully hidden past the leaf.
3. **Contempt logic (30cp, disabled below -300) worked exactly as designed**: from ply ~180 the engine was down a piece-equivalent in a R+N vs Q+P ending, correctly flipped to contempt=0, and shuffled Ra2/Rg2+ into a real threefold draw. No change needed here — but note the mistake-detector flags these repetition moves (e.g. ply 199/203/205) as blunders since SF's plain eval doesn't know about the draw; treat these as measurement noise, not real mistakes.
